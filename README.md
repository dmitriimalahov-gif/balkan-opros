# Карта процессов Balkan — постоянная ссылка

Постоянный адрес опроса сотрудников: https://dmitriimalahov-gif.github.io/balkan-opros/

Сам опрос работает на сервере компании за временным туннелем Cloudflare. `current.json` хранит его текущий адрес;
сторож сервера обновляет файл автоматически при смене туннеля. Ответы сотрудников здесь не хранятся.
