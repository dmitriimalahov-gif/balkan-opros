# Карта процессов Balkan — постоянная ссылка

Постоянный адрес опроса сотрудников: https://dmitriimalahov-gif.github.io/balkan-opros/

Сам опрос работает на сервере компании за временным туннелем Cloudflare. `current.json` хранит его текущий адрес;
сторож сервера обновляет файл автоматически при смене туннеля. Ответы сотрудников здесь не хранятся.

## Исходный код

Код сервера, интерфейса, голосового работника, ролевых сценариев и тестов находится в каталоге
[`process-survey/`](process-survey/). Инструкция по запуску и настройке — в
[`process-survey/README.md`](process-survey/README.md).

Пароли, API-ключи, база интервью, вложения сотрудников, сгенерированные отчёты, аудио и временные
файлы исключены через `.gitignore` и не публикуются.
